# Commerce — Online Auction Marketplace Platform

[![Django](https://img.shields.io/badge/Django-092E20?style=for-the-badge&logo=django)](https://www.djangoproject.com/)
[![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=for-the-badge&logo=python)](https://www.python.org/)
[![Database](https://img.shields.io/badge/Database-SQLite-003B57?style=for-the-badge&logo=sqlite)](https://www.sqlite.org/)

An eBay-inspired auction web application built with Django. Allows users to create listings, place competitive bids, maintain watchlists, post comments, and close auctions with winner determination.

---

## 🌟 Key Features
- **Listing Management**: Create listings with image URLs, starting bids, and category tags.
- **Active Listings & Category Filter**: Browse currently active auctions with real-time top bid display.
- **Bidding Engine**: Enforces strict bidding validation (bids must exceed current highest bid and starting price).
- **Watchlist Dynamics**: Add and remove listings from a personalized user watchlist.
- **Auction Closing & Winner Tracking**: Listing creators can close auctions, automatically declaring the highest bidder the winner.
- **Discussion Comments**: Leave comments and inquiries on individual listing pages.
- **Django Admin Integration**: Full administrative control over listings, bids, categories, and user comments.
